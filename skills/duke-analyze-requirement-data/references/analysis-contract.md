# 数据证据输出契约

## 1. 来源登记

每个来源至少记录：

| 字段 | 说明 |
| --- | --- |
| 文件 | 文件名或路径 |
| Sheet或数据集 | 实际分析范围 |
| 行列范围 | 有效行数、字段数或明确单元格范围 |
| 时间范围 | 数据覆盖时间；无法判断时明确说明 |
| 数据性质 | 全量、抽样、近期窗口、人工筛选或未知 |
| 样本限制 | 截断、缺字段、重复、脱敏、来源不完整等 |

## 2. 发现强度

| 级别 | 定义 | 表达方式 |
| --- | --- | --- |
| 可复核事实 | 可从提供数据直接计算或定位 | “样本中有……” |
| 样本趋势 | 样本内分布明显，但不能证明全量 | “本次样本显示……” |
| 业务解释 | 需要字段定义或业务人员确认 | “可能意味着……，待确认” |
| 推荐方案 | 基于事实和约束提出的产品建议 | 明确依赖、收益和代价 |

不要使用“系统中全部”“一直”“必然”等超出样本范围的表述。

## 3. 最小分析集

根据需求问题选择：

- 行数、字段、类型和时间范围；
- 空值数量和占比；
- 唯一值和重复值；
- 高频值及其占比；
- 异常格式、前导零和位数差异；
- 多来源字段和枚举对照；
- 关键字段组合是否支持关联；
- 极端值和少量异常样本明细。

只输出会影响需求判断的统计，不堆积与决策无关的描述性数据。

## 4. 发现到问题的转换

使用以下链路：

`数据发现 D-xxx → 业务风险 → 待确认问题 Q-xxx → 推荐方案 → 用户确认后的规则 R-xxx`

示例：

| 发现编号 | 数据发现 | 风险 | 待确认问题 | 推荐方案 |
| --- | --- | --- | --- | --- |
| D-001 | 样本中部分旧记录创建人ID为空 | 只按ID判断会漏分历史系统记录 | 历史记录性质是否允许结合名称兜底？ | 新记录强校验，旧记录查询时兼容 |

## 5. 隐私与展示

- 输出统计优先于逐条明细。
- 示例只保留判断所需字段，并对电话号码、姓名、证件号和订单号脱敏。
- 不将用户提供的数据复制到新的永久文件，除非用户明确要求保存分析产物。
