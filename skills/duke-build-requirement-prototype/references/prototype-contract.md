# 原型输出与验收契约

## 1. 页面类型选择

| 需求 | 建议结构 |
| --- | --- |
| 单一录入流程 | 单页表单或步骤式表单 |
| 列表与详情联动 | 列表、筛选区、详情抽屉或页签 |
| 历史记录 | 紧凑时间线或记录卡片 |
| 多场景差异 | 页面内场景切换器或查询参数，不复制独立文件 |
| 后台管理、运营或配置 | NG-ZORRO 风格的布局、筛选、表格和抽屉/弹窗 |
| 确认轻交互 | 原生HTML、CSS和JavaScript单文件原型 |

优先采用能最小成本验证核心规则的结构，不为展示完整度添加无需求依据的模块。

## 2. 组件体系选择

按以下顺序选择，不因使用默认组件库破坏产品一致性：

1. 既有页面、参考截图或原型工程已有明确组件体系时，保持现有体系。
2. 新建后台管理、运营或配置页面且没有既有约束时，高优先采用 NG-ZORRO 18.2.x。
3. 单文件HTML只复刻 NG-ZORRO 的组件语义、状态和视觉规范，不引入 Angular 运行时。
4. 用户提供 Angular 18 原型工程时，才实际使用 `ng-zorro-antd@18.2.x`。
5. 移动端、营销页和非后台页面不默认套用 NG-ZORRO。

后台页面的组件选择和状态要求见 [NG-ZORRO 后台原型指南](ng-zorro-admin-patterns.md)。

## 3. 规则输入分层

| 输入性质 | 原型处理 |
| --- | --- |
| 已确认业务规则 | 必须实现；关键组件标记 `data-requirement-id` |
| 原型方案 | 可演示；交付时单独说明 |
| 实现默认 | 只补足非业务交互；不得改变业务结果 |
| 数据发现 | 用于构造样例或风险场景；不得当成全量事实 |
| 待确认问题 | 保持中性或同时演示可选方案，不擅自拍板 |

## 4. 更新既有原型

### 布局微调模式

适用于间距、颜色、对齐、图标位置、换行及无业务含义的装饰调整：

1. 定位目标 DOM、直接关联的 CSS 选择器和事件绑定；
2. 只读取目标区域及其直接依赖，不默认重读完整业务需求；
3. 不新增规则编号，不同步正式文档；
4. 修改后检查目标场景、相邻布局和水平溢出；
5. 发现共享选择器、状态驱动内容或跨场景依赖时升级为规则修改模式。

### 规则修改模式

适用于文案含义、可见条件、点击行为、状态反馈、字段、枚举和业务场景变化：

1. 读取完整HTML，识别页面结构、公共样式、脚本状态和既有场景；
2. 恢复对应 `R-xxx`、`AC-xxx` 和本轮影响资产；
3. 将本轮变更映射到目标组件，避免全文件重写；
4. 保留用户已有且与本次需求无关的内容；
5. 删除组件前检查是否仍被其他场景或脚本引用；
6. 修改字段、枚举或可见条件时同步检查回显、校验、提交和时间线展示。

## 5. 场景覆盖

按需求选择必要场景，不机械覆盖全部：

- 业务对象差异：三方订单、系统订单或其他订单；
- 数据状态：空值、有值、历史数据异常；
- 操作阶段：首次进入、编辑中、提交成功、部分失败；
- 权限状态：可操作、只读、无权限；
- 内容状态：空列表、有记录、筛选无结果、分页；
- 联动状态：联系方式与联系结果、状态与原因、勾选与展开。

## 6. 交互与视觉要求

- 保持明确的主次层级和紧凑但可读的信息密度。
- 后台页面优先使用成熟组件的标准状态，不手写含义相同但行为不一致的控件。
- 关键状态、优先级、预约时间和创建人等突出信息由需求决定，不默认全部强调。
- 标签使用 `for` 关联字段；图标按钮提供 `aria-label`；图片提供 `alt`。
- 按钮明确 `type`，避免表单内误提交。
- 隐藏内容同时处理可见性和交互状态，避免不可见控件仍可聚焦。
- 错误、失败和只读状态必须有可观察反馈。

## 7. 追溯规则

示例：

```html
<section data-requirement-id="R-012 R-018">
  ...
</section>
```

- 多个编号使用空格分隔。
- 只标记承载业务行为或业务信息的关键节点。
- 规则变更后检查原型中是否仍残留已废弃编号。

## 8. 验收顺序

完成一轮批量修改后执行一次以下验收，不在每个小调整后重复启动校验或预览：

1. 运行静态检查脚本；
2. 使用 `preview_prototype.py` 启动 localhost 预览，不把 `file://` 作为默认验收路径；
3. 检查关键场景是否可进入；
4. 操作主要交互并观察状态回显；
5. 检查不同宽度下的遮挡和溢出；
6. 后台页面检查组件结构、状态和反馈是否符合所选组件体系；
7. 对照本轮规则编号检查遗漏；
8. 关闭本地预览服务，输出未完成的视觉检查或待确认项。
