# L1 轻量 Spec 与一页看板

## L1 轻量 Spec

```markdown
# 需求名称

> 原型：[页面原型](path/to/prototype.html)｜规则：[R-001～R-006](#2-功能规则)｜验收：[AC-001～AC-004](#4-验收标准)

## 1. 背景与目标
## 2. 功能规则
## 3. 异常与边界
## 4. 验收标准
```

单行原型入口只在确有原型时输出。仅在确有未确认事项时增加“待确认项”。不默认增加更新记录、名词解释、MVP、指标、非功能、上线或回滚章节；如用户明确要求版本化或既有文档已维护更新记录，将 `## 更新记录` 作为全文最后一个章节。

## 一页看板

用于会议快速对齐时，保留需求价值、目标、范围、关键规则、主导角色、完成标志和高风险提醒。存在研发执行细节时关联正式 Spec/PRD，不用看板替代规则文档。

## L1 裁剪

- 只覆盖本轮变化和真实存在的核心场景；未变化规则使用编号引用。
- 不为格式完整虚构指标、数据、异常、权限或系统影响。
- 待确认项只在确实存在时输出，不生成占位表。
